# ODA Studio — Interior Design Website

Modern, responsive, single-page interior design studio landing page.

## Çalıştırma
- `index.html` dosyasını tarayıcıda açın.
- İnternet bağlantısı; Google Fonts, görseller, GSAP ve Three.js CDN kaynakları için gereklidir.
- Sunucu zorunlu değildir. İsterseniz GitHub Pages, Netlify veya Vercel'e statik site olarak yükleyebilirsiniz.

## Teknolojiler
- HTML5, CSS3, vanilla JavaScript
- GSAP + ScrollTrigger: giriş ve kaydırma animasyonları
- Three.js: hafif dekoratif parçacık katmanı
- Unsplash: örnek iç mekân fotoğrafları

## Özelleştirme
- Metinler ve bölümler: `index.html`
- Renkler, tipografi ve responsive düzen: `style.css` (`:root` değişkenleri)
- Animasyonlar ve mobil menü: `script.js`
- İletişim e-postası örnektir; yayına almadan önce kendi adresinizle değiştirin.
- Fotoğraflar internetten yüklenir; isterseniz kendi görsellerinizle değiştirebilirsiniz.
